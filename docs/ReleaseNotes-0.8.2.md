# Solar Time–Distance Explorer 0.8.2

- Fixed Slit creation after deleting any existing Slit and prevented duplicate automatic labels.
- Added event-level regression coverage for mixed Line, Polyline, and Smooth Curve workflows.
- Grouped slope/velocity controls into one compact panel.
- Removed persistent slope endpoint circles and made velocity labels draggable.
- Added per-measurement line/text colours when Auto colors is disabled.
- Added bounded, navigable drawing history under View.
- Windows x64 onedir package includes Python, Qt, SunPy, Astropy, Matplotlib PDF support, and FFmpeg.

Extract the complete Windows ZIP and run `SolarTimeDistanceExplorer.exe`; do not move the EXE away from its `_internal` directory.
